# Лабораторна робота №8 — Основи CSS Grid Layout

## Структура проєкту

- `common/reset.css` — скидання стандартних стилів браузера (вимога №1).
- `common/variables.css` — CSS-змінні для кольорів, відступів, тіней та шрифтів (вимога №2).
- `common/download-photos.ps1` — скрипт для збереження онлайн-фотографій локально в `common/img/`, якщо потрібно.
- `task-1/` — папка для скріншота проходження гри **CSS Grid Garden**.
- `task-2/` — папка для скріншота прогресу курсу **CSS Grid** та коду уроків.
- `task-3-even/` та `task-3-odd/` — **Завдання 3**: галерея фотографій (парний і непарний варіанти) з медіазапитами `768px` та `576px`.
- `task-4-even/` та `task-4-odd/` — **Завдання 4**: сторінка з картками (парний і непарний варіанти), передбачено переповнення контенту та адаптивність `768px` і `576px`.
- `task-5/method-1-lines/` та `task-5/method-2-areas/` — **Завдання 5**: mobile-first адаптивний макет двома способами (`column grids + rows` та `grid-template-areas`).
- `task-6-even/` та `task-6-odd/` — **Завдання 6**: деревовидна структура з 28 блоків з нумерацією через CSS `counter()` (`::before`).
